# PAIR — Email & Logo Assets

This repository contains the **official image and logo assets used for the PAIR project**, including assets prepared for the project's email communications, branding, development, and deployment.

The repository serves as a centralized location for storing and maintaining the visual resources used across the PAIR system.

## 📁 Repository Contents

```text
Email-Logo-for-Pair/
├── assets/
│   ├── ...
│   └── ...
└── README.md
```

### `assets/`

The `assets` directory contains the image resources used throughout the PAIR project.

These may include:

* PAIR logos
* Email-specific logos
* Light and dark logo variants
* Branding images
* Icons and supporting graphics
* Other visual assets required by the PAIR system

The assets are maintained separately so they can be reused across different parts of the project without duplicating the same files in the main application repository.

## 🎨 Purpose

The assets in this repository are used to support the **PAIR Guardian Portal** and its related project materials.

They may be referenced by:

* Email notifications
* Email templates
* Application interfaces
* Deployment environments
* Documentation
* Project presentations
* Other PAIR-related materials

## 🖼️ Asset Usage

When adding or updating an asset, please keep the following in mind:

* Use clear and descriptive filenames.
* Preserve the original image quality whenever possible.
* Keep light and dark variants clearly distinguishable.
* Avoid unnecessarily duplicating the same asset.
* Use appropriate image formats depending on the intended use.
* Keep branding consistent with the PAIR project.

## 📌 Relationship to the PAIR Project

This repository is an **asset-only repository** and is not the main source code repository for the PAIR Guardian Portal.

It is intended to provide a centralized location for visual resources that can be referenced by the PAIR system and its supporting services.

## 🔗 Related Project

**PAIR Guardian Portal**

PAIR is a guardian-focused portal developed for the **LEAPhigh Tutorial Center**. The system supports guardian-related functions and project communication, including email-based notifications that may use the assets maintained in this repository.

## 🛠️ Development & Deployment

This repository does not contain the main application source code or application runtime.

Its primary purpose is to store and maintain the visual assets required by the PAIR project during:

* Development
* Testing
* Email configuration
* Deployment
* Documentation

When an asset is updated, the corresponding PAIR application or email configuration should be checked to ensure that references to the asset remain valid.

## 📂 Asset Management Guidelines

When contributing new assets:

1. Place the asset in the appropriate directory under `assets/`.
2. Use a descriptive filename.
3. Avoid spaces and unnecessary special characters in filenames when possible.
4. Verify that the asset displays correctly in its intended location.
5. Check both light and dark environments when applicable.
6. Commit the change with a clear commit message.

Example:

```bash
git add assets/
git commit -m "assets: update PAIR email logo"
git push
```
